# Contributing and Getting Paid

Thank you for considering a contribution! Follow these steps to get paid for your work.

1. **Claim your GitHub login**  
   Visit https://www.mergit.xyz/claim and link your wallet to your GitHub account.

2. **Choose a funded issue**  
   Browse the repository’s issues and pick one that already has a bounty attached.

3. **Create a pull request**  
   - Fork the repo (if you haven’t already).  
   - Implement the fix or feature.  
   - In the PR description (not just the title) add `Closes #<issue-number>` (e.g., `Closes #29`).  
   - Only one PR per funded issue is allowed.

4. **CI must be green**  
   The repository’s CI runs automatically. The PR will be merged only after the checks pass.

5. **Merge and payment**  
   When the PR is merged, the Mergit agent pays the wallet you claimed in step 1 and comments a receipt on the PR.

**First‑time contributors from a fork**  
The first PR from a new fork requires a maintainer to manually approve the CI run. This is normal and ensures the agent can verify the build.

That’s it – happy hacking!
